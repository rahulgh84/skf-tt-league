League Rules

Match Format

Best of 3 games. Each game is to 11 points. Win by 2.

Service Rules

The server must toss the ball upward before contact. The ball must be visible and not hidden. Serve starts behind the end line and must touch server side first, then opponent side.

Basement Rule

If the ball hits the ceiling or any basement obstruction, point goes to the opposite player.

Settings

Passwords are stored in Firebase settings for convenience. This is basic protection for a community site, not enterprise authentication.
